# Rawdah Quran Journey

أريد أن أصمم لـ CV يكون احترافي وكذلك راقي وجذاب بألوان ملفتة، وأيضًا يكون فيه سهل التنقل للتعرف علي. أريد أن تكتب لي فيه اسمي روضة الحلبي، عمري 21 سنة، وأني ساكنة في مكة المكرمة، وأيضًا هواياتي السباحة والقراءة وركوب الخيل. بالإضافة إلى أنني تخرجت من معهد دبلوم الدراسات القرآنية، معهد سفرة، بعد جولتي السابقة. وأريد أن أصممه لي بشكل جميل واحترافي حتى يتعرف علي الناس.
